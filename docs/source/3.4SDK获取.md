------------------------

```
ssh jetson@192.168.144.3        #密码:lxai2023

```

3.4.2 获取对应固件版本的sdk
-------------------------

目前SDK支持基于TCP通信方式，提供X86及ARM架构的SDK包。另一方面，使用高层接口和底层接口的调用方式不同，根据不同的需求，请在查询到版本号后，截图发送给技术支持同事获取对应版本的sdk包
